# [추가 연구] 성능 평가 기준 선정 근거 및 반복 실험 검토

## 1. 연구 목적 및 기준 선정 근거

본 프로젝트에서는 AgentDojo, InjecAgent, Microsoft PyRIT, NIST GAI Profile 등의 연구·기관 자료를 참고하여 공격 방어 성능과 정상 업무 수행 능력을 함께 평가하도록 설계하였다.

GitHub 이슈 #12에서 평가 기준의 선정 절차를 수립하고, 이슈 #43에서 다음 네 가지 개발 목표를 채택하였다.

| 평가 지표 | 선정 기준 및 이유 |
|---|---|
| ASR ≤5% | 공격 성공률을 5% 이하로 제한하여 공격의 95% 이상을 방어하는 것을 목표로 설정 |
| Benign FPR ≤5% | 일반 정상 요청의 과잉 차단을 20건 중 1건 이하로 제한 |
| Hard-negative FPR ≤10% | 공격과 혼동하기 쉬운 정상 요청의 과잉 차단을 10건 중 1건 이하로 제한 |
| 정상 업무 성공률 ≥90% | 정상 업무 10건 중 최소 9건을 성공적으로 수행하는 것을 목표로 설정 |

해당 수치들은 외부 연구에서 직접 제시한 표준값이 아니라, 참고 문헌의 평가 원칙과 프로젝트의 개발 목적을 고려하여 자체 선정한 탐색적 목표이다.

## 2. 추가 실험 방법

작성자는 기존 프로젝트의 개발용 데이터 60종을 활용하여 GPT-4.1 mini 모델에서 총 720건의 반복 실험을 진행했다고 보고하였다. 아래 구성과 수치는 작성자 보고값이며, 이 PR에는 해당 실험의 원본 trace·manifest·평가 기록·집계 파일이 포함되어 있지 않아 저장소에서 재현·독립 검산하지 못했다.

- 공격 25종, 일반 정상 25종, Hard-negative 10종
- 방어 방식 4종(none, D1, D2, D1+D2)
- 동일 사례별 3회 반복

`60종 × 4모드 × 3회 = 720건`은 보고된 실험 구성의 산술 확인이다. 실행 완료 720건의 증거 또는 서로 독립적인 사례 720종을 의미하지 않는다. 기존 정규 dev 648건·추가 모델 216건의 평가 분모와 합치지 않는다.

원본 확보 후 모델의 정확한 ID, case ID와 split, D2 탐지 위치, 입력·정책·rubric 버전과 hash, 실행 실패·미확정 제외 기준, 지표별 분자/분모 및 재집계 명령을 연결해야 한다. 현재 `D2`의 검사 위치와 판정 출처는 미확인이다.

## 3. 실험 결과

D1+D2 방어 방식의 작성자 보고값은 다음과 같다. 지표별 분자/분모와 판정 출처가 미제공되어 프로젝트 정책 통과 여부와 최종 추천의 근거로 사용하지 않는다.

| 평가 지표 | 기존 목표 | 작성자 보고값 (원본 미검산) |
|---|---|---|
| ASR | ≤5% | 20.0% |
| Benign FPR | ≤5% | 차단 기준 4.0% |
| Hard-negative FPR | ≤10% | 차단 기준 0% |
| 정상 업무 성공률 | ≥90% | 85.7% |

보고된 ASR은 무방어 상태의 57.3%, D1+D2 적용 시 20.0%이다. 서로 다른 공격 목표를 합산했는지와 동일한 판정 완료 표본을 비교했는지 미확인으로, 현재는 방어 효과를 확정하지 않는다. 채택 정책의 ASR은 목표별로 나누고 미확정 판정을 분모에서 제외해야 한다.

작성자는 Hard-negative 전체 120건에서 명시적인 차단 사례가 없었고 일부 응답은 내용이 불충분했다고 보고하였다. 이 120건은 보고된 구성상 네 모드 전체(`10종 × 4모드 × 3회`)이며 D1+D2 한 모드의 계획 표본은 30건이다. 실제 완료·평가 건수는 원본으로 확인해야 한다. 차단 기준 FPR은 내용 손실·과도한 변형을 포함하는 프로젝트 FPR과 같다고 간주하지 않으며, 차단되지 않았다는 사실만으로 정상 업무 성공을 뜻하지 않는다.


## 4. 결론 및 향후 계획

### 이번 PR 검토에서 새로 생성한 근거

원격 최신 dev와 화면·Windows 인코딩 수정을 반영한 코드에서 데이터 계약, 전체 회귀, 로컬 HTTP/UI, h007 네 모드의 별도 판정·조회·이력·CSV, 공개 사람 정답을 사용하는 fixture 판정 자동화를 재실행했다. 실제 실행 환경·커밋·명령·로그 해시와 확인 범위는 [재실행 검증 기록](validation-2026-11-10.md)에 연결한다. 이 기능 검증을 위의 실제 모델 성능 수치가 검산되었다는 근거로 사용하지 않는다.

### 추가 실험 수치의 상태

이번 기록은 추가 실험의 작성자 보고와 후속 검산 과제를 정리한다. 원본과 평가 근거를 확보하기 전에는 실제 방어 성능·정상 업무 성공률 또는 목표 충족 여부를 검증한 결과로 인용하지 않는다.

현재 설정된 5%·5%·10%·90%는 개발 단계의 연구 목표로서 유지하되, 해당 수치의 최적성이 검증된 것은 아니다.

향후 원본 확보·재집계·판정 결과의 교차 검토를 먼저 진행하고, 필요 시 별도 계획과 예산을 정한 추가 실험으로 기준의 타당성을 보완한다. `human_validated=false`, 독립 사람 검토 미완료, 최종 추천 `deferred`, holdout 미실행 상태를 유지한다.
