# 4주차 데이터·판정 근거 정리

## 1. 데이터 및 평가 범위

1~3주차 데이터와 평가 기준, 실제 dev 실험 결과를 정리했다.

기존 자동 평가와 AI 연구 판정(`week3-two-ai-review-v0.1`)은 구분하며, 원본 데이터 및 기존 평가 결과는 변경하지 않았다.

### 데이터 구성

| 구분 | 수량 |
|---|---:|
| RAG 케이스 | 84건 |
| RAG 문서 | 52건 |
| 공격 / 정상 / Hard-negative | 각 28건 |
| 한국어 / 영어 | 79건 / 5건 |
| Dev / Holdout | 75건 / 9건 |
| 이메일 케이스 / 문서 | 3건 / 3건 |
| D2 target gold | 48행 |

데이터 목록과 실제 실행 대상은 구분한다. 실험에 적용된 데이터·corpus·평가 버전은 각 실행 기록을 기준으로 확인한다.

Holdout 9건은 보존했으며 이번 평가에 사용하지 않았다.

## 2. 실험 구성

### 2.1 정규 dev 실험

| 실험 구분 | 최종 출력 | D2 검사 대상 |
|---|---:|---:|
| 기존 payload·정상 대조 | 324 | 306 |
| 원본·인용 대조 | 108 | 99 |
| D2 조작 대조 | 216 | 216 |
| **합계** | **648** | **621** |

비교한 방어 구성은 다음과 같다.

- `none`: 방어 없음
- `D1`: 프롬프트 기반 방어
- `D2`: 입력·검색 문서 탐지 기반 방어
- `D1+D2`: 두 방어 결합

D2는 입력 검사, 검색 문서 검사, 양쪽 검사로 구분했다.

실험별 데이터·공격 목표·비교 조건이 다르므로 세 배치를 하나의 ASR로 합산하지 않는다.

### 2.2 별도 실험

| 실험 | 실행 규모 | 구분 |
|---|---:|---|
| #41 탐색 감사 | 계획 942건 | 별도 공격 탐색 |
| 4주차 실제 재현 | 108건 | 기존 기능·실행 재현 검증 |
| GPT-4.1 mini | 108건 | 추가 모델 실험 |
| GPT-4.1 | 108건 | 추가 모델 실험 |

정규 dev 실험, 탐색 감사, 4주차 재현 및 추가 모델 실험은 서로 다른 평가 범위로 관리한다.

## 3. 평가 지표 및 판정 기준

| 지표 | 평가 내용 |
|---|---|
| ASR | 공격 목표 달성 비율 |
| Benign FPR | 정상 요청에 대한 방어 오탐률 |
| Hard-negative FPR | 공격처럼 보이는 정상 요청의 방어 오탐률 |
| 정상 업무 성공률 | 정상 업무 수행 성공 비율 |
| D2 FNR/FPR | 실제 검사 대상에 대한 탐지 미탐·오탐률 |
| p50/p95 | 응답 지연 |
| 비용 | 토큰 사용량·API 호출 기반 추정 비용 |

평가에는 기존 Week3 정책과 rubric을 적용한다.

미확정 판정(`review_needed`)은 임의로 성공 또는 실패로 변경하지 않으며, 판정 완료 분모가 0이면 해당 비율을 `null`로 유지한다.

신뢰구간(CI)은 독립 family 20개 이상과 평가 완료 관측 또는 짝 60개 이상이라는 표시 하한을 충족하고 독립성도 확인된 경우에만 표시한다.

반복 실행이나 문구 변형을 독립 family로 중복 계산하지 않는다.

## 4. AI 검토 및 미확정 판정

| 항목 | 결과 |
|---|---:|
| 최종 출력 판정 | 648개 |
| D2 검사 대상 판정 | 621개 |
| 전체 평가 task | 1,269개 |
| 중복 제거 원증거 | 283종 |
| 두 AI 최초 합의 | 218종 |
| 제3 AI 조정 | 65종 |
| 미확정 원증거 | 23종 |
| 미확정 원증거 연결 task | 72개 |

미확정 원증거에 연결된 72개 task는 다음과 같이 구분한다.

| 구분 | 실행 수 | 공격 성공 판정 |
|---|---:|---|
| A10 공격 | 18개 | `review_needed` |
| 정상 | 36개 | `not_applicable` |
| Hard-negative | 18개 | `not_applicable` |

A10은 보호값 제공 여부가 불명확해 공격 목표 판정 18개가 제외됐다.

이에 따라 각 방어 조건에서 ASR은 `null`로 유지된다.

AI 검토 및 제3 AI 조정 절차는 완료되었지만 실제 사람의 독립 검토는 수행되지 않았다.

세부 내용은 `data-review-detail.md`에서 관리한다.

## 5. 검산 및 추가 모델 실험 결과

### 5.1 공개 집계 검산

저장소의 공개 평가 자료와 실행별 판정을 대조한 결과는 다음과 같다.

| 검산 항목 | 결과 |
|---|---:|
| 전체 집계 그룹 | 168개 |
| 최종 출력 그룹 | 144개 |
| D2 target gold 그룹 | 24개 |
| 산술 검산 | 864개 항목, 불일치 0건 |
| 실행별 판정 대조 | 576개 항목, 불일치 0건 |
| 최종 출력 실행 연결 | 648개, 누락·중복 0건 |
| D2 검사 대상 연결 | 621개, 라벨 집계 일치 |

공개 집계와 저장된 실행별 판정의 계산·연결 일관성을 확인했다.

다만 원시 모델 응답의 의미 판정 정확성까지 독립 검증한 것은 아니다.

### 5.2 추가 모델 실험 및 비용

| 모델 | 실행 수 | API 호출 | 추정 비용 |
|---|---:|---:|---:|
| GPT-4.1 mini | 108 | 198 | $0.0415388 |
| GPT-4.1 | 108 | 198 | $0.1483852 |
| **합계** | **216** | **396** | **$0.189924** |

PR #49에서 두 모델 실험의 실행·사용량·API·JSON·CSV 일치 및 중단 후 재개 검증이 완료된 것으로 기록됐다.

이 비용은 관측 토큰과 적용 단가에 따른 추정치이며 실제 청구액은 아니다.

별도 4주차 재현 실험은 108개 논리 실행, 199개 provider 호출이 기록됐으며, 확인된 비용 부분합은 약 $0.041702다. 전체 비용은 미확정이다.

## 6. 검증 상태 및 결론

| 항목 | 상태 |
|---|---|
| 공개 평가 집계·실행별 판정 검산 | 완료 |
| PR #49의 두 모델 기술 검증 | 완료 기록 확인 |
| 4주차 재현 배치의 화면·API·CSV 일치 | 완료 기록 확인 |
| 과거 648회 원시 응답의 독립 검증 | 미완료 |
| 과거 648회 최종 보고서·화면 수치 대조 | 미완료 |
| 실제 사람 검토 및 A/B/C 최종 인수 | 대기 |

공개 평가 자료를 통해 데이터 구성, 평가 기준, 정규 dev 실험 결과와 미확정 판정의 집계 처리를 확인했다.

그러나 전체 원시 응답 검증과 최종 팀 인수가 완료되지 않았으므로 최적 방어 구성을 확정하지 않는다.

**최종 추천은 `deferred`로 유지하며, holdout 평가는 수행하지 않았다.**
