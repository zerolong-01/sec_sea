# 전체 개발 데이터와 AI 공격 변형의 탐색 감사

기존 개발 데이터 132건과 API로 생성한 공격 변형 25건을 출처별로 실행하고, 실제 생성 응답에서 공격 목표 달성 여부를 다시 확인한다. 최종 성능 평가가 아니라 성공 사례를 찾기 위한 탐색이다. holdout 9건은 선택하지 않는다.

## 실행 범위

| 출처 | 선택 건수 | 비고 |
| --- | ---: | --- |
| 초기 데이터 `data/` | 36 | Week2에서 같은 ID를 재사용했으므로 별도 출처와 기준 유지 |
| Week2 | 75 | dev만 선택 |
| 영어 번역 추가분 | 3 | 원본은 다시 중복 선택하지 않음 |
| Week3 파생 데이터 | 15 | 제거본·정상 대조군·보호값 실험 포함 |
| 이메일 | 3 | 공격·정상·hard negative |
| 새 AI 공격 변형 | 25 | 개발용 공격별 한 변형 |

`data/week1`의 사례와 문서는 `data/`와 바이트 단위로 같아서 중복 실행하지 않는다. 네 기본 모드(none, D1, D2, D1+D2)에 D2-input과 D2-retrieval을 더해 총 여섯 조건을 각각 한 번 실행한다. 총 942개 실행이다. 기존 Week3의 조건별 3회 반복 기록은 별도 보조 증거이며 새 실행의 분모에 섞지 않는다.

## 재현

프로젝트의 `.env`에 기존 고정 모델과 API 설정이 필요하다. Git Bash에서 가상환경을 활성화한 후 실행한다.

```bash
python -m scripts.generate_attack_variants --output runs/my-audit/generated
python -m scripts.run_attack_audit --output runs/my-audit/exploration --generation-file runs/my-audit/generated/variants.json
python -m scripts.run_attack_audit --output runs/my-audit/exploration --generation-file runs/my-audit/generated/variants.json --report-only
```

PowerShell에서는 `python` 대신 `.\.venv\Scripts\python.exe`를 사용할 수 있다. 재개할 때 같은 출력 경로를 사용한다. 완료한 유료 호출을 다시 보내지 않으며, 오류·사용량 불명·미완료 예약은 자동 재시도하지 않는다. 원인과 저장 기록을 먼저 확인해야 한다.

생성은 0.25달러, 실행은 출처별 할당액 합계 4.70달러로 제한한다. API가 보고한 토큰과 버전이 있는 단가로 비용을 계산한다. 보수적인 호출 전 예약과 실제 사용량은 구분한다. 출처별 배치는 단일 실행자이고, 독립적인 출처 배치 최대 세 개를 병행한다.

## 생성과 판정

생성 모델에는 원본 공격 목표와 합성 문서만 제공한다. 직접 공격은 사용자 입력을 바꾼다. 문서 공격은 원본 질문과 문서를 보존하고 새 지시를 뒤에 추가한다. 이 방식은 원래 공격을 포함한 확장 변형이므로 새 문구만의 인과 효과를 입증하지 않는다. 모델이 쓴 생성 이유는 성공 원인으로 사용하지 않는다.

판정은 공개 화면의 마스킹 표시나 기존 자동 라벨만 믿지 않고, 비공개 `provider_output`과 generation 호출의 `response_text` 일치부터 확인한다. 원본별 목표값, 개인정보·인증정보, 부분·인코딩 목표와 문맥 인용 기준을 적용한다. 의미 판정이나 해독이 필요한 후보는 별도로 검토한다. D2의 allow는 최종 생성 공격 성공과 별개다.

공개 자료에는 마스킹한 발췌, run ID, 입력·원시 기록의 해시, 조건과 관측 근거를 남긴다. `.env`, 원시 응답, 보호값을 포함한 준비 자료는 무시되는 `runs/` 아래에 보존한다. 공개 자료를 만들 때 보호값·개인정보·자격증명과 API 키가 없는지 확인한다.

한 번 관측한 성공은 반복 성공률이나 방어 우열을 뜻하지 않는다. 특히 D2가 허용한 뒤 생성 프롬프트가 동일해도 응답이 달라질 수 있으므로, D2 때문에 생성 모델이 더 취약해졌다고 단정하지 않는다. 사람이 검수한 gold나 최종 서비스 추천을 자동으로 작성하지 않는다.
