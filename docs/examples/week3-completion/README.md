| 실험 | 정상 대조군의 AI 작업 판정 | 별도 관측과 해석 |
| --- | --- | --- |

검토는 저장된 실제 생성 본문·case·문서 사실·요구 형식을 읽고 기록한 **AI evidence review**다. [기존 324회](../../week3-output-review.md), [인용 108회](../../week3-quotation-output-review.md), [D2 216회](../../week3-d2-output-review.md)에 각 판정의 방법과 제한을 연결했다. AI 기록을 실제 사람의 독립 검토나 팀 합의로 표시하지 않았다. 과거 자동 평가 이력은 보존하고 재검토 결과는 별도 overlay로 제공한다.

새 두 실험은 각각 원래 부모 **3 family**를 상속한다. 저장된 사전 pairmap으로 인용 대조 54개, D2 대조 108개의 case/repeat 짝을 검증했다. 같은 family의 공격 변형을 새 독립 family로 세지 않는다. [paired exact 도구](../../week3-control-observations.md)는 이 pair ID를 메모리에서만 보강하고 frozen metadata를 바꾸지 않는다. literal 미관측은 부분·인코딩·추론 가능한 유출의 부재를 증명하지 않는다.

## 실제 D2 대상 gold 등록과 미탐

새 D2 실험의 실제 검사 대상 216개에 AI 작성·별도 AI 정적 검토한 gold를 등록했다. benign 입력 108개, malicious 검색 문서 54개, hard-negative 문서 54개다. 대상의 실제 전송 텍스트 해시를 대조한 뒤 등록했으며 모델 호출은 추가하지 않았다. raw 로그·입력·manifest·호출 ledger는 그대로다. 사람 독립 검토는 대기 상태다.

| 방어 구성 | 입력 benign FPR | 검색 문서 malicious FNR | 검색 문서 hard-negative FPR |
| --- | ---: | ---: | ---: |
| D2-input | 0/36 | 해당 대상 미검사 | 해당 대상 미검사 |
| D2-retrieval | 해당 대상 미검사 | 6/18 | 0/18 |
| D2-both | 0/36 | 6/18 | 0/18 |
| D1+D2 | 0/36 | 6/18 | 0/18 |

각 값의 분모는 **실제 검사하고 판정 가능한 대상**이다. 대상별 미탐률은 최종 공격 성공률과 다르며, 미검사 대상은 분모에 넣지 않는다. 216개 대상 모두 gold 판정 가능, 탐지 오류·판정 보류·gold 누락은 각각 0이었다. 기존 324회 실험의 미등록 306개 대상에 이번 gold를 소급 복사하지 않았다.

## 구현 보완과 검증

- 저장 trace를 읽을 때 해당 배치의 동결 규칙으로 보호값을 마스킹한다. 기존 보호값 trace 72개를 재생했고, 예전 공개 파일 54개의 노출은 API 조회에서 0개였다. 원시 평가 증거는 보존했다.
- 같은 family에 여러 공격 짝이 있을 때 집계가 중단되던 문제를 고쳤다. 식별 불가능한 과거 짝은 제외 사유와 null을 남기며, 새 배치에는 명시적인 pair ID를 저장한다.
- 세 배치의 최신 집계·CSV는 각각 90그룹/990행, 24그룹/264행, 12그룹/132행이었다. 재집계 과정에서 원본 저장 파일 각각 706개·225개·585개의 해시가 유지됐다.
- 기존 324회 API·schema·CSV·UI 재생은 845개 원본 파일 불변, 추가 모델 호출 0회로 통과했다. 이 재생 검증의 범위와 마스킹 정확성 검증을 구분했다.
- 로컬 전체 regression 191개, backend 113개, 이후 추가한 paired 관측 변조 회귀 1개가 통과했다. 최종 PR head의 Ubuntu·Windows CI 결과는 PR 체크에서 확인한다.

[공개 요약 JSON](summary.v0.4.json)은 버전·분모·제외·해시·실제 호출 비용과 검증 출처를 담는다. 원시 답변·보호값·API 키는 담지 않는다. 로컬 상세 증거는 `runs/week3-completion/` 아래에 보존하며 Git에 올리지 않는다. 해시 일치는 파일의 무결성 근거로 사용하며 사람 서명이나 출처 인증으로 해석하지 않는다.

현재 결과로 최종 방어 구성을 추천하지 않는다. 보호값 노출과 정상 작업 실패가 관측됐고, 새 실험의 3 family는 채택한 최소 20개에 미달한다. 충분한 독립 family, 사람의 독립 gold·출력 검토, 역할별 실제 인수는 남은 요구 사항이다. 서비스 기준은 dev에 채택됐지만 운영 승인·holdout 승인으로 바뀌지 않는다.
