## 1. 바꾼 것

| 영역 | 전 | 후 |
| --- | --- | --- |
| 케이스 선택 | 사이드바의 긴 라디오 목록 | **케이스 찾기** 탭: 검색·앱/라벨/언어 필터·정렬·10건 페이지·미리보기·필터 초기화. 사이드바에는 선택한 케이스 요약과 대표 케이스만 |
| holdout | 구분 없음 | 기본 숨김, 보기만 가능, 선택 버튼 없음, 실행 버튼 3개 비활성 |
| 결과 화면 | 상태 줄 → 단계별 trace(왼쪽)·메타 정보(오른쪽) | **① 실행 조건·상태 → ② 출력과 평가 요약 → ③ 단계별 trace·판정 근거**. 300자 넘는 입력·출력, 조립된 프롬프트, 실행 설정, 모델 호출은 접기 |
| 상태 표시 | 글자만 | 색 + 아이콘 + 글자 (✅ 좋음 · ❌ 나쁨 · 🛡️ 방어가 막음 · ⏳ 아직 모름 · • 해당 없음). 공격 "성공"은 빨강, 풀이 문구 함께 |
| 대시보드 | 필터 상자가 항상 펼쳐져 KPI가 아래로 밀림 | 필터는 접고 제목에 적용 중 필터 표시. 비교표는 방어 조건 → 주요 지표 → 추천 판단 순, 방어 조건 열 고정 |
| 평가 출처 | 없음 | 대시보드 위쪽 출처 칸, AI 연구 판정은 별도 페이지 |

값은 모두 서버 응답을 그대로 옮긴다. 화면에서 지표·판정을 새로 계산하지 않았다.
