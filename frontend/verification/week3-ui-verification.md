# 3주차 배치 대시보드 통합 검증 기록 (#35)

작성일: 2026-10-20
대상 화면: `frontend/pages/1_배치_대시보드.py`
서버: `python -m scripts.mvp serve --runs-dir runs/week3-real` (실제 모델 `.env`)

## 1. 확인 방법

1. 백엔드 배치 명령(`scripts.week3_batch`)으로 실제 모델 배치를 만들고 실행한다.
2. 대시보드에서 해당 배치를 고르고 **내보내기 → 리포트 JSON 내려받기**를 한다 (필터 없음).
3. 같은 배치를 CLI로 다시 집계한다.
   `python -m scripts.week3_batch --runs-dir runs/week3-real report <batch_id>`
4. 두 JSON을 통째로 비교한다. 화면 표·산점도·추천 사유는 이 JSON을 글자로만 바꾼 것이므로
   JSON이 같으면 화면 값의 출처가 서버 집계와 같다는 뜻이다.

조회·필터·내보내기는 모델을 호출하지 않는다. 2번째 배치를 같은 번호로 다시 `run` 했을 때도
호출 수·비용이 그대로였다 (완료 항목 재호출 없음).

## 5. 다른 담당에게 필요한 것

- 정상 성공률·FPR·산점도: 평가 담당의 검토 필요 판정과 과도 변환 검토 (#33)
