# 3주차 배치 대시보드 데모 안내 (약 3분)

대상: 교수님 면담, 팀 공유
사용 배치: `batch-4d5d49d420c6` (실제 모델 gpt-4.1-mini, RAG + 이메일, 108건)

## 준비 (데모 전에 미리)

1. 서버와 화면을 켠다. 모델을 다시 부르지 않으므로 비용이 들지 않는다.
   ```
   .venv\Scripts\python -m scripts.mvp serve --runs-dir runs/week3-real
   ```
2. 브라우저에서 http://127.0.0.1:8501/배치_대시보드 를 연다.
3. "볼 배치"에서 `batch-4d5d49d420c6`를 고른다.

## 질문이 나오면

- **화면 값이 맞는지 어떻게 아나?** 화면에서 내려받은 JSON·CSV가 CLI로 다시 만든 리포트·CSV와 같다는 것을 확인했다 ([검증 기록](week3-ui-verification.md)).
- **왜 ASR이 전부 0%인가?** 대표 공격 케이스가 앱마다 1개(3회 반복)뿐이라 표본이 작다. 그래서 CI 없음·표본 부족으로 표시된다. 방어 효과의 결론이 아니다.
- **비용은 얼마나 들었나?** 108건에 약 $0.041 (표준 단가 추정). 대시보드 조회·내보내기는 0원이다.
- **다음은?** 평가 담당 판정이 들어오면 정상 성공률·FPR·산점도가 채워진다. 팀 정책이 확정되면 추천 후보와 Pareto 상태가 표시된다.

## 데모 중 주의

- 서버를 켠 PowerShell 창은 닫지 않는다.
- 새 배치를 실행(`run`)하지 않는다. 데모에는 저장된 결과만 쓴다.
- `.env`나 키가 보이는 창은 화면 공유에서 뺀다.
