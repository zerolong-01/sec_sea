④ 원하는 질문을 검색해서 고르고 싶어요 자세히 비교하기 방어 모드 실행 · trace 확인 탭 → 케이스 찾기
⑤ 여러 질문을 한꺼번에 돌린 결과를 보고 싶어요 자세히 비교하기 배치 대시보드 탭 → 배치 선택 (미리 실행해 저장한 결과만 볼 수 있어요)
⑥ AI 모델끼리 결과를 비교하고 싶어요 자세히 비교하기 모델 비교 탭 → 실험 선택
⑦ 결과를 파일로 내보내 과제로 내고 싶어요 자세히 비교하기 각 탭의 CSV 준비 → CSV 다운로드
